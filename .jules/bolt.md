## 2026-10-16 - Early Exit in Audit History and Windows Temp Cleanups
**Learning:** `AuditLogger.history()` in `backend/security/audit_log.py` previously performed multi-pass list comprehensions over the full record array before slicing. Using `reversed()` iteration allows exiting as soon as `limit` matching items are collected, achieving an ~4x speedup ($O(\min(N, \text{limit}))$). Additionally, on Windows CI runners, test temp dir cleanup in `fs.rmSync()` can encounter transient `EPERM` errors while processes release file handles; adding `{ maxRetries: 10, retryDelay: 100 }` prevents flaky test failures.
**Action:** Use reverse early-exit loops for timestamped/history queries that request the most recent $K$ records, and configure retry options on `fs.rmSync` when tests spawn child processes on Windows.
