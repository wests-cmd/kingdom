# Assistant capabilities — candidate

Extends the independently implemented Quick Kingdom interaction pattern inspired by Atticus (MIT, https://github.com/SaarthurR/atticus-mac). No upstream source or assets were copied.

## Use from Talk & work or Quick Kingdom
- Harness: select a configured CLI, explicitly enable process work, and send the objective. The request pins the profile revision. The existing process approval and task executor govern the job; its working directory is not an OS sandbox. Continue saved request to collect its retained result. A process exit is not proof of repository correctness.
- Learn this verified instant command: name a completed deterministic command from the same session/project. Replay only the built-in read-only operation. No arbitrary learned shell, automatic promotion, or permission grants.
- Text-only fallback: select explicit primary and fallback models. One fallback for an incomplete response only. Both receive permitted conversation references. No fallback after transport/authorization errors. Connection revisions are pinned.
- Voice: local-only is the default; unsupported or missing on-device recognition refuses recording. Explicitly opting out can permit the browser speech provider. This is not a bundled Whisper engine.
- Screen region: choose a screenshot file or use supported screen picker, mark and preview a rectangle, attach a compressed crop and select one vision profile. Review before sending. The crop is retained in the request database; do not include sensitive information. No continuous capture, remote image URL, automatic cloud fallback, or automatic clicks. A marked rectangle is not live desktop guidance.
- Platform observation: Windows retains its existing accessibility/input implementation. Optional X11 xdotool and macOS osascript probes return exact foreground identity only, with empty controls and input_supported=false. No auto-installation, accessibility grants or Wayland bypass. macOS/Linux input remains disabled.
- Delegation: select a local group and approved member Knight; text analysis only. Existing signed RPC, leases, grants and independent result verification remain authoritative. Shared group authority is held rather than silently replaced. Group tasks are held after interrupted execution and cannot silently fall back outside the group.

## Safety and recovery
Request submission uses persisted admission checkpoints. An interrupted submission is uncertain: inspect retained task metadata by conversation_request_id before any retry. Linked jobs can be cancelled through the normal task controls. A cancellation does not establish that an in-flight external process or its side effects stopped. Evidence is retained. No extra scheduler, approval system, secret store or model service is introduced.

## Acceptance
Require exact-head full backend/distributed tests, frontend/desktop tests, dependency checks, native installer verification and documentation checks. Added regression coverage includes shortcut provenance, scoped delegation assignment/version checks, explicit image routing, fallback, harness revision drift, admission interruption and optional platform probe boundaries. Live model/voice and native macOS/Linux accessibility/input, annotation overlays, autonomous workflow learning, multi-agent Commander planning and physical machine commissioning remain open. Do not equate mocked adapter tests with a working physical installation.


## Expanded implementation (verification pending)
- Harness wrappers may explicitly select `kingdom_jsonl` output. Each line is a JSON object: {"type":"progress","message":"Working"}, {"type":"proposal","tool":"text.analyze@1.0.0","text":"literal input"}, or {"type":"answer","text":"Final text"}. Exactly one answer, at most 64 events and five proposals; only text and Python analysis proposals. Ordinary CLIs keep text mode. While running, Kingdom records elapsed time and output bytes, not raw stdout. Verified proposals can create a new unapproved mission draft; external harnesses do not get Kingdom tool authority. No claim of provider-native live token streaming or mediation of an external harness's own tools.
- Verified completed missions with 2–12 literal text/Python checks become reviewable reusable candidates. POST /missions/{id}/replay-candidate recreates a new unapproved draft after rechecking exact task receipts; existing approvals are never inherited. Arbitrary action learning is not enabled.
- Optional synthetic text benchmark: owner selects a configured model and sends three fixed short requests. It may use provider quota/charges. Store exact-match score, average latency and revision. Opt-in measured auto-routing considers only otherwise eligible, fresh, passing profiles and never asserts general intelligence from this suite.
- Local transcription: set KINGDOM_WHISPER_CLI and KINGDOM_WHISPER_MODEL to trusted absolute local paths. Model at most 250 MiB, 2 threads, one local slot, 120-second timeout, 16 kHz mono PCM WAV up to 60 seconds/2 MiB. No automatic downloads; local engine availability does not prove a usable transcription. The supplied CLI is an owner-trusted host executable, not a sandbox. Use the file picker in voice controls, then review the transcript. Physical microphone and native speech model tests remain open.
- Visual guidance: select a crop, choose an explicit vision model and ask for teaching marks. Model rectangles are constrained to the reviewed image, rendered with numbered labels, and never execute input. They remain advisory. The native packaged smoke uses a non-sensitive generated image to verify the actual crop UI and verifies nothing is submitted without Send. The private Docker fixture captures the real isolated display; neither establishes OS screen picker consent or a live overlay on the physical host.
- Private X11 keyboard: experimental restricted container adapter uses fresh title/window identity and reviewed printable ASCII or allowed key actions. It requires the explicit KINGDOM_PRIVATE_X11_INPUT flag, non-root Docker, private :99 display and xdotool. The launcher must establish actual isolation; environment checks are not a sandbox. Offline GUI CI now exercises this adapter and independently verifies Tk input and screenshot. Normal Linux/Wayland and macOS input remain disabled. macOS foreground probe identifies process/window title only; not full accessibility or safe input.
- Commander: select a local group and model to draft 2–8 pure-analysis steps with pinned group membership and computers. The draft is linked to the conversation. Review and approve the exact version under Missions; existing scheduler/leases and controller verification decide dispatch/completion. Group revision changes hold work. No broad autonomous side-effecting delegation or independent model-review team claim.
- Published v1.2.9 is the last verified installed release until this expanded PR passes every gate. The new branch does not replace existing artifacts.
