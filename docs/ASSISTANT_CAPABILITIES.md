# Assistant capabilities — candidate

Extends the independently implemented Quick Kingdom interaction pattern inspired by Atticus (MIT, https://github.com/SaarthurR/atticus-mac). No upstream source or assets were copied.

## Use from Talk & work or Quick Kingdom
- Harness: select a configured CLI, explicitly enable process work, and send the objective. The request pins the profile revision. The existing process approval and task executor govern the job; its working directory is not an OS sandbox. Continue saved request to collect its retained result. A process exit is not proof of repository correctness.
- Learn this verified instant command: name a completed deterministic command from the same session/project. Replay only the built-in read-only operation. No arbitrary learned shell, automatic promotion, or permission grants.
- Text-only fallback: select explicit primary and fallback models. One fallback for an incomplete response only. Both receive permitted conversation references. No fallback after transport/authorization errors. Connection revisions are pinned.
- Voice: local-only is the default; unsupported or missing on-device recognition refuses recording. Explicitly opting out can permit the browser speech provider. This is not a bundled Whisper engine.
- Screen region: choose a screenshot file or use supported screen picker, mark and preview a rectangle, attach a compressed crop and select one vision profile. Review before sending. The crop is retained in the request database; do not include sensitive information. No continuous capture, remote image URL, automatic cloud fallback, or automatic clicks. A marked rectangle is not live desktop guidance.
- Platform observation: Windows retains its existing accessibility/input implementation. Optional X11 xdotool and macOS osascript probes return exact foreground identity only, with empty controls and input_supported=false. No auto-installation, accessibility grants or Wayland bypass. macOS/Linux input remains disabled.
- Delegation: select a local group and approved member Knight; text analysis only. Existing signed RPC, leases, grants and independent result verification remain authoritative. Shared group authority is held rather than silently replaced. Group tasks are held after interrupted execution and cannot silently fall back outside the group.

## Safety and recovery
Request submission uses persisted admission checkpoints. An interrupted submission is uncertain: inspect retained task metadata by conversation_request_id before any retry. Linked jobs can be cancelled through the normal task controls. A cancellation does not establish that an in-flight external process or its side effects stopped. Evidence is retained. No extra scheduler, approval system, secret store or model service is introduced.

## Acceptance
Require exact-head full backend/distributed tests, frontend/desktop tests, dependency checks, native installer verification and documentation checks. Added regression coverage includes shortcut provenance, scoped delegation assignment/version checks, explicit image routing, fallback, harness revision drift, admission interruption and optional platform probe boundaries. Live model/voice and native macOS/Linux accessibility/input, annotation overlays, autonomous workflow learning, multi-agent Commander planning and physical machine commissioning remain open. Do not equate mocked adapter tests with a working physical installation.
