# Kingdom Command Center (Vantage-inspired)

The Swarm → Network map page now contains one SVG workspace with three views: Network, Team organizer, and Live work. The design is independently implemented from the interaction ideas in [Vantage](https://github.com/levi-xy/vantage/tree/803b47f65089329fbf369df2a0c931d770a87da3) (MIT). No Vantage code, icons, device credentials, services, or monitoring stack were copied.

- **Network**: computer-shaped Knight cards and reported status. Blue indicates local controller or a current signed peer inventory report; red indicates a reported disconnection/restriction; gray is unknown. Cables represent known peer reporting relationships, not physical wiring or direct verified transport paths. CPU and memory display only when a current peer report is available and a valid measurement exists.
- **Team organizer**: frames for existing teams, Captain labels, hosted Apprentices when their reports are current, and reporting lines based on the saved coordination graph. Reporting lines do not relocate software or grant capabilities. Expand the reporting relationship editor to review and save changes separately.
- **Live work**: reported job counts/status, tools, models, worker identity, and services through the selected card inspector. Missing reports mean unknown work, never zero. A reported completion is not independent acceptance evidence.
- Edit layout enables drag/keyboard positioning and moving visible members as a frame. Frame size can be increased through the inspector; it always contains its visible members. Undo/redo applies only to unsaved geometry. Save is a version-checked, owner-authenticated local SQLite transaction. Reload on a conflicting save; the unsaved draft is retained until explicitly discarded. Auto arrange resets this view's visual positions only.
- Team membership is explicitly edited using the existing group actions, including create, move, combine, split, leadership and removal. Moving a visual card/frame does not even propose membership edits. Shared group changes still go through their authority controller; when that authority is unavailable, membership edits are disabled. Visual layouts are local to each controller and independent per view.
- Search and paging limit each rendered canvas to 40 participants. Hidden/offline identities can retain positions but never reappear as a real entity solely because of a layout record. On small screens the inspector appears below the scrollable canvas. No new graph library or background service.
- Acceptance: pure geometry and history tests, authenticated API persistence and conflict tests, production frontend build, and native smoke exercising the actual map, layout edit, undo/redo and persisted layout without membership changes. Physical multi-computer and touch ergonomics need separate verification.
