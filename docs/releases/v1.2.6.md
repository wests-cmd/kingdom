# Kingdom v1.2.6

## Changes

- Give the security changes already merged in main a new release identity. The
  previous main publication correctly refused to replace existing 1.2.5 assets.
- Include the known-compromise package gate merged in PR 171, together with the
  patched desktop dependency tree delivered in 1.2.5. The gate runs before
  supported source installers invoke package installation.
- Synchronize backend, desktop, frontend and mobile version metadata using the
  repository's version preparation command. Retain historical release receipts.

## Validation and limits

- The pre-version main commit passed backend/frontend CI and real Windows,
  Linux and macOS native installer checks. Those receipts establish the source
  baseline; they do not replace checks for the exact 1.2.6 candidate.
- Publication remains gated on native builds, independent installer smoke tests,
  dependency audits, matching source identity and downloaded artifact checksums.
- No new trust policy, agent capability, worker identity or model qualification is
  granted by this release. Hardware rollout preserves each installation's data
  and credentials and requires its own backup, health and rollback checks.
- Phone signing, general autonomous development and permanent OS installation
  are not certified by these desktop release checks.
