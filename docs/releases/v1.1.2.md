# Kingdom v1TAS v1.1.2

This release adds accessible appearance controls, owner-approved operational recovery and durable workflow checkpoint snapshots.

- Settings: high contrast, interface size up to 200%, larger controls/pointer, strong keyboard focus, reading space, reduced distraction and reduced motion. Preferences work before sign-in and on device connection screens, persist locally and can be saved to the owner's SQLite database. These settings never grant permissions or approve actions.
- Recovery: actual readiness/runtime status, explicit review and approval of a runtime restart, expiring single-use plans, competing-repair rejection and recorded verification/failure. Unsupported legacy repair placeholders no longer claim success.
- Checkpoints: versioned workflow, completed-step and consumed-budget snapshots survive a process restart. Invalid saves retain prior snapshots. Loading a snapshot does not execute or authorize a workflow.
- Reviewed maintenance: credential redaction handles non-string keys and unhashable sanitized sets; learning-history lookup stops after enough recent valid records while preserving legacy zero/negative limits. Desktop build dependency `http-cache-semantics` is updated to 4.3.0; the high-severity audit gate remains enabled.

The owner-confirmed AgentScope checklist is recorded in `docs/AGENTSCOPE_ADDITIONS.md`, with remaining gaps in `docs/AGENTSCOPE_PROGRESS.md`. This release does not certify all 56 additions, full assistive-technology compatibility, automatic code repair, signed live updates, or complete workflow resume.

Supported installer targets are **Linux x86_64 AppImage/DEB**, **Windows x86_64 NSIS**, and **macOS Intel x86_64 DMG**. Release publication requires all three native jobs to build, install/start, complete a real verified task, and verify appearance/accessibility persistence. Hashes, the source commit, platform evidence and screenshots are attached to the release. Python and Node.js are not required separately by desktop users.

Windows and macOS installers are unsigned; the Mac DMG is not notarized. Apple Silicon, Windows ARM64, Linux ARM64, Android and iOS installers are not supplied. A browser device companion exists, but receives no owner or task-execution authority.

Close Kingdom before upgrading, retain your per-user data and profile, and verify the installer against `SHA256SUMS`. Automatic in-place desktop upgrades are not provided. AI text needs a configured provider; broker connections, live market data and trade execution are unavailable.
