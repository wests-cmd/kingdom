# Kingdom v1.2.9

## Changes
- Quick Kingdom: compact native Electron assistant, keyboard shortcut and tray entry, using the authenticated unified conversation. It has no privileged preload and does not start the microphone automatically.
- Instant read-only requests and owner-defined project-scoped aliases without a model call. Existing grants, agent tasks, budgets, and durable request identities remain authoritative.
- Connection repair: signed inventory reply correlation, atomic endpoint and heartbeat updates, honest transport status and peer reconnect state. Includes merged PR #194.
- Disposable private Linux GUI verification fixture (PR #189): actual X11 input and independent screenshot evidence in a restricted container. This fixture is not an integrated computer-control worker.
- Correct verified published v1.2.8 README installer links until this new version is actually published.

## Verification
Before publishing, require exact-source backend CI, frontend build, dependency gates, documentation navigation, and Windows/Intel macOS/Linux native verification. The packaged smoke test must submit a deterministic status request through Quick Kingdom and retrieve the same saved result from the main renderer. Unit tests cover shortcut scope, duplicate-request identity, denied executable aliases and desktop lifecycle. These are acceptance requirements, not a claim that every check has already passed.

## Limits
No copying of Atticus source/assets or shell replay; the interaction pattern is independently implemented. Voice uses the existing reviewed browser transcript workflow, not a certified offline native speech engine. No automatic screen capture, verified arbitrary action learning, universal harness orchestration, or production background GUI control is introduced. Physical global shortcut behavior, installed-machine security commissioning (#172), Apple Silicon, signed mobile packages and fleet rollout remain separate. Windows and Intel macOS installers remain unsigned; macOS is not notarized. Never replace previously published release assets.
