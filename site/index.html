The core idea

A harness that grows with the work.

Plan bounded work, place it on suitable resources, execute with approved tools, verify the outcome, remember useful evidence and adapt the next assignment.

01

Choose your connections

Use configured model providers and optional agent adapters. Kingdom's direction is model and harness independence; Hermes is an option, not a requirement. Compatibility depends on the adapter and available hardware.

02

Bring computers together

Pair approved machines and grant explicit capabilities. Current distributed execution is bounded; read the delivery gates before expecting arbitrary remote coding or pooled model memory.

03

Keep evidence and authority

Persistent tasks, reusable skills and reviewed knowledge support the workflow. Models propose actions; permission checks and verification govern execution. Stored chat alone is not proof of learning.
